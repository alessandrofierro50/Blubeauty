# BluBeauty — Identità visiva

Logo scelto: **monogramma "bb" a farfalla** (proposta B, 31/10/2026).
Due "b" speculari formano le ali di una farfalla: richiama la trasformazione e la bellezza, e il "bb" di BluBeauty.

## File (`public/brand/`)

| File | Uso |
|---|---|
| `blubeauty-logo.svg` | Logo principale, sfondi chiari |
| `blubeauty-logo-dark.svg` | Sfondi scuri |
| `blubeauty-logo-mono.svg` | Monocromatico nero: scontrini, timbri, fax, incisioni |
| `blubeauty-mark.svg` | Solo simbolo (avatar social, favicon) |
| `blubeauty-app-icon.svg` / `-192.png` / `-512.png` | Icona app / PWA |

La scritta è convertita in tracciati (Inter ExtraBold + Inter Light): non serve avere il font installato.
Favicon e icona Apple dell'app: `src/app/icon.svg`, `src/app/apple-icon.png`.

## Font
Inter (Google Fonts, licenza OFL) — ExtraBold per "Blu", Light per "Beauty", Regular/Medium/SemiBold per l'interfaccia.

## Regole
- Area di rispetto attorno al logo: almeno l'altezza della "B".
- Dimensione minima: simbolo 16 px, logo completo 100 px di larghezza.
- Non deformare, ruotare, cambiare colori o separare scritta e simbolo nel logo completo.

Le proposte scartate sono in `docs/brand/proposte/`.
